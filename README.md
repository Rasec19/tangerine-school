# Tangerine School

![Tangerine school logo](/src/assets/LOGO-tangerine.webp)

Tangerine School is a interactive online english school.

This is the lading page whith the objetive to offer them services.

## How to serve

1. Use command to install dependencies.
```
npm install
```
or
```
yarn install
```
This commando will install all node dependencies.

2. To serve landing pafe in dev server.
```
npm run dev
```
or
```
yarn dev
```

Command to run a developer mode server in local.

## Build and deploy

1. Use build command.
```
npm run build
```
or
```
yarn build
```
This commando gonna create a dist folder in the root, this folder has all the content to deploy to production.

1.5. Get up a preview serve (optional)
```
npm run preview
```
or
```
yarn preview
```
This command gonna serve a preview server similar a production server in local.

2. Commmand to deploy page.
```
npm run preview
```
or
```
yarn preview
```

This will deploy the dist or ditribution folder to the main branch linked to github pages hosting using gh-pages library.
